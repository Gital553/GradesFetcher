# קדימון שנתי — מדע וטכנולוגיה, כיתה ד׳

סרטון קדימון באורך 3 דקות (1920×1080, 30fps) המרונדר במלואו מקוד: אנימציית
מושן־גרפיקס, טיפוגרפיה עברית קינטית ופסקול מסונתז. אין קבצי מדיה חיצוניים ואין
צורך בגישה לרשת בזמן הרינדור.

התוכן מעוגן בארבעת מסמכי המקור: שלושת מערכי השיעור (תצפית מול פרשנות, מאפייני
חיים, צרכי קיום) והפריסה השנתית עם ארבעת השערים.

## מבנה הסרטון

| זמן | מערכה | תוכן |
|---|---|---|
| 0:00–0:45 | תצפית, פרשנות וסקרנות | חולדת הקנגורו במדבר · טל · מקרי גבול (אש, ענן, רובוט) · תצפית מול פרשנות · קיר השאלות |
| 0:45–1:30 | שער א׳ — בעלי חיים | דוב קוטב · גמל · דג זהב · חמשת צרכי הקיום · הטבלה כדפוס |
| 1:30–2:15 | שערים ב׳–ג׳ | מצב מצוי ומצב רצוי · תמסורת וגלגלי שיניים · מצבי צבירה · מחזור המים |
| 2:15–3:00 | שער ד׳ — הגוף | שכבות העור · מפרק ציר ומפרק כדור־שקע · שלד בתנועה · סיום |

## הרצה

```bash
pip install pillow numpy python-bidi fonttools imageio-ffmpeg
apt-get install -y fonts-noto-core          # Noto Sans Hebrew

python3 soundtrack.py                       # build/soundtrack.wav
python3 render.py                           # ../science_trailer_grade4.mp4
```

דגלים שימושיים:

```bash
python3 render.py --frame 72.5 --png /tmp/f.png   # פריים בודד לבדיקה ויזואלית
python3 render.py --scenes 10,11                  # רינדור שוט בודד (איטרציה מהירה)
python3 render.py --crf 18 --preset slow          # איכות גבוהה יותר, קובץ גדול יותר
```

## מבנה הקוד

| קובץ | תפקיד |
|---|---|
| `render.py` | ציר הזמן (23 שוטים), רינדור מקבילי והזרמה ל‑ffmpeg |
| `scenes.py` | כל שוט כפונקציה טהורה `f(t, p, frame) -> RGBA` |
| `creatures.py` | חיות ואיברים המצוירים פרוצדורלית |
| `draw.py` | פרימיטיבים: גרדיאנטים, זוהר, ויניאטה, גרעיניות, easing |
| `hebrew.py` | טקסט עברי — סידור ויזואלי ונפילה חכמה לפונט משני |
| `soundtrack.py` | הפסקול: ארבעה פרקים תואמי מערכות |
| `score.py` | סינתיסייזר (מקורו בסקיל `video-soundtrack`) |

## שתי מלכודות שכדאי להכיר לפני שינוי הקוד

**עברית ב‑Pillow.** ה‑Pillow כאן בנוי עם Raqm, שמריץ את אלגוריתם ה‑BiDi בעצמו.
שילוב שלו עם `python-bidi` היה הופך את הטקסט פעמיים — כלומר טקסט מראה. לכן
`hebrew.py` טוען כל פונט עם `layout_engine=ImageFont.Layout.BASIC` ומבצע את
הסידור במקום אחד בלבד. בנוסף, Noto Sans Hebrew הוא פונט עברי בלבד: אין בו פסיק,
סימן שאלה או ספרות — ולכן כל שורה מפוצלת לקטעים לפי כיסוי הגליפים, וכל קטע מצויר
בפונט שמכיל אותו. בלי זה כל סימן פיסוק היה מופיע כריבוע.

**`ImageDraw` דורס פיקסלים, לא ממזג אותם.** ציור צורה שקופה־למחצה מעל צורה
אטומה באותה שכבה חותך בה חור. כל אלמנט שקוף (שלג, בועות, אבק, קשת טווח התנועה)
מצויר לכן על שכבה נפרדת שמורכבת עם `alpha_composite`.
